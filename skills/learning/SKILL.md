# Learning——系统性教学工作区

目标是**理解**，不是复述：事实能从学习者已接受的基础推导出来、连接进其心智模型，因而自我保持。一切教学动作都在学习者脑中构建这张**依赖图**——少数核心真理在根部，其余事实挂在上面推导得出。教学奏效的体感是 **the click**：孤立事实坍缩成少数生成性想法的瞬间——以它为目标。

## 会话怎么跑（五步）

1. **探测工作区**——`docs/mission.md` 不存在 → 使命访谈（≤2-3 轮）后初始化 mission 与 resources；已存在 → 读 docs/ 三件 + 扫描 lessons/，从上次前沿续接，错题优先重教
2. **目标访谈**（不判分）——把"我想理解 X"追到具体为止；零基础默认，不测绘
3. **规划**——researcher 摸底 → 依赖图（压测根部）→ 呈现计划（散文 + mermaid），非阻塞直接开教
4. **教学循环**（以小节为单位）——逐节点连续讲述（动机 → 确立 → 连接）→ 每讲完一小节产出配对文件（课程 HTML + 检索练习页）→ 跑 `check-lesson.py` 自检 → 学习者浏览器作答提交，报告直写 docs/answer.md
5. **收尾三查**——错题落档 / 悬空自明 / 资源沉淀（见文末红线清单）

**工作区 4 类文件**（一律小写英文，wikilink 互链）：`docs/mission.md`（锚）· `docs/resources.md`（可信资源）· `docs/answer.md`（练习与错题档案）· `lessons/`（`000N-<slug>.html` 课程 + `000N-<slug>-question.html` 练习页 + 配图 `*.png`）。进度自证：课程存在即已讲，answer.md 有记录即已练。

## 触发分层

- **L1 解释**——教学语境内的顺带讲解、答疑。只适用两条原则 + 准确性核实（数学写 LaTeX），**不建任何文件**。
- **L2 教学会话**——学习者明确要"学/教"。完整流程（五步）+ 学习工作区全部产物。L1 中察觉系统学习意图时主动提议升级。

**跨主题裁决**：已有使命的工作区里，中途冒出的其他主题默认按 L1 处理，不落文件不污染本主题档案；明确要**换**目标时——确认 → 新工作区初始化 mission → 旧工作区原样保留。answer.md 中反复出现的错题模式是方向优化信号，据此修订使命前同样先确认。

## 教学哲学——两条原则

**原则 i：无条件的真理优先。** 先锁定少数无条件真理——学习者可照字面直接接受、无限定无例外的硬事实——其余一切显式构建其上，让学习者看清每个新事实踩在什么地基上。

- 术语区分：*无条件真理*是**持有方式**（照单全收），*公理*是**图位置**（无入边的根）。默认说前者，别因为听起来基础就叫公理。
- 一条事实需要限定或例外，它就还不是——继续向下挖。小而稳胜过大而晃。
- 强形态优先找：**全称陈述**（"所有 X 都是通过 {____} 完成的"原子单元式要显式点出）；**真正的定义**（不是特征清单）。没有干净的不要硬凑。
- 向上构建前确认地基——不牢就停下来修，不在沙子上盖楼。

**原则 ii："我怎么可能自己发现这个？"** 显得武断的事实锁不住。带着学习者走一遍发现之路，每步都有动机：为什么做这件事？为什么试这个方法？什么会让人想到这条路？产出是给依赖图**加边**（孤立命题 → 连接命题）。3Blue1Brown 是风格锚：无中生有的东西不存在，每个动作都让人感觉是自己伸手够到的。

**讲述式是唯一形态**——连续叙述这条发现之路，零提问零打断；教程是量身输出的成品，不是轮次对话。检验不在讲解中途，而在每个小节末的检索练习。

**流利 vs 存储强度**：临场流利给虚假掌握感，长期保持才是目标。检索练习只是及格线；用合意困难建存储强度——**提取练习**（判分题天然是；错题重教与确认题也是）、**间隔**（复习分散到后续会话）、**交错**（仅限技能练习）。加压的分界：额外合意困难仅适用技能类主题；讲解正文零打断，判分只在练习页（技能类的练习反馈循环不算打断）。

**知识 vs 技能**：知识类主题困难是敌人——讲平顺，别让费解跳跃挤占工作记忆；技能类主题困难是工具——反馈循环尽可能紧，最好立即、自动。

## 学习工作区

选址：空目录或专用学习目录就地作为工作区；非空一般目录（尤其代码仓库）先与学习者确认，默认独立目录，不经确认不落文件。状态文件集中 `docs/`，教学产物留根：

- `docs/mission.md`：学习者**为什么**学。一切教学以它为锚。格式见 [mission-format.md](./references/mission-format.md)；修订前先确认。
- `docs/resources.md`：可信资源与社区清单。格式见 [resources-format.md](./references/resources-format.md)。
- `docs/answer.md`：**练习与错题档案**——每次检索练习一条：`## <课程基名> · <日期> · <对>/<总>`，其下逐条错题（题面 | 我答 | 正确答案 | 缺口说明）；**全对也记**（已练证据）。数据来自练习页生成的作答报告（浏览器直写追加；回退复制贴回由教师落档）；页面已判，教师只核实不重判。未划销错题驱动下次重教——重教通过确认题即划销（保留可见，标已清除）。首次练习落档时创建。
- `lessons/*.html`：课程与练习**配对产出**——`000N-<slug>.html`（正文与配图，按 [template.html](./assets/template.html)）+ `000N-<slug>-question.html`（题面 + 内嵌答案与判分脚本，按 [question-template.html](./assets/question-template.html)）。
- `lessons/*.png`：配图与课程同目录（`visualize` 派 maker 产出）；`lessons/src/` 是 maker 中间产物，含共享的 `katex/`。

**会话开始**（语言始终跟随学习者）：

1. **探测**：`docs/mission.md` 不存在（大小写不敏感，`MISSION.md` 等旧名视为同一文件；根目录旧布局原位沿用不迁移）→ 新工作区：使命访谈（不判分，≤2-3 轮；动机空缺就如实记"动机暂缺"——不许据此不建文件），初始化 mission 与 resources。续接：读 docs/ 三件 + 扫描 lessons/——**前沿 = 最后一个已练课程**；练习文件在而档案无记录 = 悬空，优先补练；教学计划读最新课程左栏（快照）。错题驱动：未划销错题所涉知识点优先排入重教。
2. **开场零提问**：不设开场复习——跨会话提取练习由错题驱动承担。

**会话结束**：练习报告已落档并核实；未提交的练习页即悬空自明；本次核实与调研的可信源登记 resources.md。教课前先查 resources.md，不从零搜索——researcher 摸底与事实核实的可信产出都应登记进来。

## 流程：目标访谈 → 规划 → 教学

三个阶段永远按序全跑；缩放规模，绝不缩放形状。

**准确性铁律**：对任何事实、名称、日期、公式有一丝不确定，先核实再说出口——优先派 `researcher` 子代理；不可用则自带 WebSearch/WebFetch 亲自核实；都不可用则明示"此条未经核实"。准确性永远压过流畅；核实修正了内容就直说。

### quiz 协议（出题与判分）

- **检索练习（默认）**：按 question-template 产出练习页——≤4 道单选题、内嵌答案与判分脚本、"不知道"固定末项、标题"<课程标题>的检索练习"。学习者浏览器**凭记忆**作答、点提交——页面当场判分（✓/✗ + 正确答案 + 简短解释）并生成作答报告（直写 answer.md，回退复制/下载）。答案内嵌页面脚本（源码可见）——自测场景可接受。
- **确认题**：错题重教后的单题钉子，用 `AskUserQuestion` 出，立即判分。
- **判分规则**：选项恒为 4——1 正确 + 2 干扰 + 1 "不知道"（二选一辨析题允许 3 项）。答案不进题面直读范围。自然语言作答按核心断言判分：含实质错误即 ✗ 并指出错处，不为部分正确给 ✓；至多一轮澄清。"不知道"常驻不裁量，让"真不会"与"蒙错"可区分。正确答案位置轮换。
- **选项构造程序**（所有判分题适用）：
  1. 每个选项都是**裸断言**——理由一律放判分后的解释里；
  2. 先写正确断言，再用**同骨架、同粒度、同语域**把它变异成每个干扰项——各选项是"不同信念下的同一断言"；
  3. 干扰项必须是学习者可能真犯的错——诱人，不刁钻；
  4. 加粗要么全无要么每项对应位置都有——只突出正确项会暴露答案。

  写完冷读：不懂材料也能看出哪个对，就重新生成，不打补丁。

### 阶段 1 — 学习目标（不判分）

**零基础默认**：不测绘不摸底考，从无条件真理起教；口头声明的既有知识可作起点参考；误解暴露时当场指出、讲清为什么错。把学习愿景追问到具体——"我想理解 LLM"可以指十种东西，具体哪一种决定教什么。

### 阶段 2 — 规划（杠杆率最高，不要赶）

- **先派 `researcher` 摸底**——核心概念、真正的第一性原理、常见坑；不可用则自带搜索。**摸底不可省，只换执行者。**
- 对着哲学规划：哪些无条件真理、有无原子单元、有动机的发现路径是什么、知识还是技能、反馈循环怎么搭；`docs/answer.md` 未划销错题优先排入重教。
- **压测根部**：每个基础节点问"对*这个学习者*真是无条件真理，还是伪装的定理"——推得出来就压下去，不把课程奠基在半山腰。
- **呈现计划**（永远在教学之前）：散文思路（覆盖什么、顺序、为什么，锚定使命）+ 小型 mermaid 依赖图（根=无条件真理，汇点=目标）——这张图就是教学顺序。**非阻塞**：声明"有异议随时喊停"后直接开教。

### 阶段 3 — 教学（连续讲述 + 小节末检索练习）

一次一个**节点**构建依赖图；每 2-3 个节点构成一个**小节**。每个节点三步：

1. **给动机**——为什么现在需要它、解决什么问题（无条件真理也不例外）；
2. **确立**——基础真理平直陈述（有原子单元就点出）；推导步骤走有动机的发现之路；
3. **连接**——依赖边显式化，新节点挂在哪些已就位的节点上。

发现自己正断言一个只能靠信仰接受的事实——停下：补动机，或奠基到已确立的东西上。

**小节末**：产出配对文件（课程 + 练习页，规格见 quiz 协议与课程制作规范）→ **产出即自检**：运行本技能 `assets/check-lesson.py <课程> <练习页>`——校验外链资产、占位残留、锚点一致、题数；未通过当场修，通过才继续 → 告知学习者：学完课程后打开练习页凭记忆作答、提交 → 报告直写 answer.md，学习者回来说一声、教师读文件核实（不重判）。**教学流不回头**——错题由下次会话重教，本次保持节奏。未提交即悬空。

**错题重教**（续接会话）：未划销错题所涉知识点优先重教（换讲法、补动机）→ 确认题钉住 → 答对划销。

## 最近发展区

教"地板之上、目标之下、且最相关"的东西。地板来源：跨会话读 answer.md 练习记录与未划销错题 + 使命定位相关性；**默认地板为零**——无证据不假设既有知识，证据只上移地板。学习者指定确切目标则以其为准；超使命主题走跨主题裁决。

## 智慧与社区

学习者问出需要智慧的问题：先尝试回答，最终交棒社区。主动找高信誉社区登记进 resources.md"智慧"组；学习者拒绝加入则记一行备注，不再反复提议。

| 浏览器操作、页面演示 | `browser-act` |
| Obsidian 格式约定 | `obsidian-markdown` |

## 课程制作规范

课程是**唯一落盘教学产物**——会话不落盘，对话即过程、课程即沉淀。**一门课程 = 一个小节**，命名 `000N-<dash-case-name>.html`，编号取 lessons/ 现有最大加一。

- 按 [template.html](./assets/template.html) 设计系统制作（奶油画布、衬线标题、深墨代码窗、珊瑚点睛；模板缺失时以四视觉词自建精简系统不阻塞）。轻量 HTML（约 20KB），无外部网络依赖。
- **三栏**：左 = 全部计划小节导航（已发布可点、未发布置灰、当前高亮）；中 = 正文；右 = 本节大纲（页内锚点）。**导航是快照**——新课程发布不回填旧文件。
- **数学**：写 LaTeX（行内 `$x$`、独立 `$$…$$`），TeX 源码保留在 HTML，KaTeX 浏览器端渲染。仅当本节有公式：① Bash 把技能 `assets/katex/` 三件复制到 `lessons/src/katex/`（全工作区一份共用；**勿读入上下文**）；② 保留模板的相对外链与渲染调用。无公式课程删外链块；资产缺失时 TeX 源码原样显示；资产不可用降级 MathML。
- 课程要短——待在学习者工作记忆内，但给一个可继续搭建的具体收获；直接服务使命、落在最近发展区。
- 每门课程：推荐一个首选一手资源（resources.md 中最可信的）+ 一条"有问题随时问 agent"提醒；可用 CLI 为学习者打开。
- docs/ Markdown 的数学一律 LaTeX：行内 `$f(x)$`、展示 `$$` 独立成行围栏——写 $f(x) = x^2$，不写 `f(x) = x^2`。**例外**：练习页选项经 KaTeX 渲染后须单行易读（避免矩阵与多行结构）；确认题选项走弹窗无 KaTeX，用单行记号或文字描述。

## 红线清单——任何时候不可违反

**Never**

- 不重判练习页已判的结果——教师只读 answer.md 核实
- 不回填旧课程的左栏导航（快照语义）
- 讲解中途不出题、不打断——判分只在小节末练习页与错题确认题
- 不凭记忆断言有一丝不确定的事实——先核实（researcher → 自带搜索 → 明示未核实）
- 不把 assets/katex/ 读入上下文——一律 Bash 复制
- 不跳过阶段顺序；不经确认不在别人的项目里落工作区文件
- 教学配图不用 `illustration`

**Always**

- 产出配对文件即跑 `assets/check-lesson.py`，未通过不进下一小节
- 开场零提问；答错只记录不回头；悬空自明（练习文件在而档案无记录）
- 工作区文件一律小写英文；教学语言跟随学习者
- 准确性永远压过流畅；核实修正了内容就直说，不悄悄糊弄

**收尾三查**（会话结束前过一遍）

1. **错题落档**——练习报告已入 docs/answer.md（全对也记），已核实
2. **悬空自明**——未提交的练习页留在原处，下次会话优先补练
3. **资源沉淀**——本次核实与调研的可信源已登记 docs/resources.md
