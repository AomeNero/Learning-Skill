# Learning Skill 流程详解（维护者视图）

> 定位：**流程规格书**——供修改、优化 `SKILL.md` 时对照使用。按会话时间线组织：每个阶段给出步骤、交互属性、文件产物。所有可调数值集中列在文末 [§9 可调参数表](#9-可调参数表优化入口)。
>
> 交互属性图例：🔴 **判分**（有对错，立即反馈）｜🟡 **对话**（不判分，收集偏好/信息）｜🟢 **无交互**（教师/子代理独立执行）｜📄 **产物**（文件落盘）
>
> 当前流程版本：**三阶段制**——目标访谈 → 规划 → 教学（小节末考核）。零基础默认、无测绘、无 Socratic、无会话末总判；**考核独立为配对 question.html，页内自判分、报告贴回落档**，错题驱动跨会话。工作区 **4 类文件**：docs/ 下 mission / resources / answer + lessons/（课程、考核页与配图）。

## 1. 会话开始（阶段 0）：工作区探测

| 属性 | 内容 |
|------|------|
| 触发 | 学习者明确表达学习意图（"教我 X"） |
| 交互 | 🟡 仅新工作区有使命访谈；续接**开场零提问** |
| 产物 | 📄 新工作区：`docs/mission.md` + `docs/resources.md` |

### 步骤

1. **选址**：空目录或专用学习目录 → 就地作为工作区；非空一般目录（尤其代码仓库）→ 先确认目录（🟡 一次确认）。
2. **探测**：`docs/mission.md` 不存在 → 新工作区；存在 → 续接。**兼容条款**：文件名大小写不敏感匹配（`MISSION.md` 等旧名视为同一文件）；旧布局（根目录 MISSION.md）原位沿用不迁移。
3. **新工作区分支**：使命访谈（🟡 ≤2-3 轮；给不出动机如实写"动机暂缺"，不许据此不建文件）→ 按格式初始化 `docs/mission.md` 与 `docs/resources.md`。
4. **续接分支**（🟢）：读 `docs/`（mission、resources、**answer.md**），扫描 `lessons/` 目录——**课程即已讲，考核档案即已考**：课程存在即已讲；answer.md 有其考核记录即已考。前沿 = 最后一个已考课程；考核文件在而档案无记录 = 悬空，优先补考；教学计划读最新课程左栏。**错题驱动**：answer.md 未划销错题所涉知识点在教学顺序中优先排入重教。
5. **开场零提问**：不设开场复习——提取练习由错题驱动机制承担。

## 2. 阶段 1——学习目标（不判分）

| 属性 | 内容 |
|------|------|
| 交互 | 🟡 目标追问，无对错 |
| 产物 | 无直接文件（口头声明的既有知识作起点参考） |

- **零基础默认**：不测绘、不摸底考。地板定在零，从无条件真理起教；口头声明的既有知识可作起点参考。误解不预设——暴露时当场纠正并讲清为什么错。
- 把愿景追问到具体为止（"我想理解 LLM"可以指十种东西，具体是哪一种完全决定教什么）。

---

## 3. 阶段 2——规划

| 属性 | 内容 |
|------|------|
| 交互 | 🟢 摸底与设计；🟡 计划呈现（**非阻塞**） |
| 产物 | 📄 `docs/resources.md` 增量（摸底可信产出；计划不落独立文件） |

### 步骤

1. **researcher 摸底**（🟢）：派子代理调研主题（核心概念、第一性原理、常见坑）；不可用则自带搜索；两者都不可用则明示。**摸底不可省**。
2. **设计依赖图**（🟢）：无条件真理（有无原子单元）、错题重教需求（answer.md）、有动机的发现路径、知识/技能定性。
3. **压测根部**（🟢）：每个基础节点问"对*这个学习者*它真是无条件真理吗"——推得出来就压下去。
4. **呈现计划**（🟡 非阻塞）：散文思路 + 小型 mermaid 依赖图；声明"有异议随时喊停"后直接开教。
5. **计划不落独立文件**：呈现只发生在对话；教学顺序随后固化进课程左栏导航（快照）。首门课程产出前会话中断的，下次重新规划。

---

## 4. 阶段 3——教学（连续讲述 + 小节末考核）

| 属性 | 内容 |
|------|------|
| 交互 | 🟢 讲述零打断；🔴 学习者浏览器作答考核页并提交（每小节 ≤4 题）；🔴 错题重教后确认题 |
| 产物 | 📄 每小节：课程 + question.html 考核页；报告落 answer.md；另有配图（lessons/*.png） |

### 小节循环

```
对每个节点（无条件真理 + 非平凡推导步骤）：
  1. 给动机 —— 为什么现在需要它、解决什么问题
  2. 确立   —— 基础真理平直陈述 / 推导走有动机的发现之路
  3. 连接   —— 依赖边显式化
每 2-3 个节点构成一个小节 →

小节末：
  ① 产出配对文件（📄）：课程 000N-<slug>.html（正文）+
     000N-<slug>-question.html 考核页（≤4 题，答案内嵌判分脚本）
  ② 学习者作答（🔴）：浏览器打开考核页，单选作答后点击提交——
     页内逐题 ✓/✗ + 答案 + 简短解释，生成作答报告（复制/下载）
  ③ 报告落档（📄）：学习者把报告贴回对话，教师按格式追加 docs/answer.md
     （不重判；全对也记，作为已考证据）——教学流不回头，补教留给下次会话
  ④ 配图（🟢 条件触发）：visualize → diagram-maker → lessons/*.png
```

### 续接会话的错题重教

教学顺序中优先安排 answer.md 未划销错题所涉知识点的重教（换讲法、补动机）→ 重教后出一道确认题（🔴）→ 答对即从 answer.md 划销该条（保留可见，标记已清除）。

### 途中规则

- **准确性警报**：对任何事实有一丝不确定 → 停下核实（researcher / 自带搜索 / 明示未核实）。
- **信仰警报**：发现自己正断言一个只能靠信仰接受的事实 → 停下：补动机，或奠基到已确立的东西上。

## 5. 会话结束——落盘清单（🟢）

| 产物 | 条件 |
|------|------|
| 📄 `docs/resources.md` 增量 | 高质量可信源沉淀；学习者拒绝社区等偏好在此记一行备注 |
| 📄 answer.md | 考核报告回收落档；未回报的考核文件即悬空（自明），下次优先补考 |

## 6. 交互点汇总表（学习者视角——"什么时候要跟我说话"）

| # | 交互点 | 阶段 | 类型 | 规模上限 | 能否跳过 |
|---|--------|------|------|----------|----------|
| 1 | 工作区选址确认 | 会话开始 | 🟡 | 1 次 | 仅在代码仓库等非空目录触发 |
| 2 | 使命访谈 | 会话开始 | 🟡 | ≤2-3 轮 | 不跳——动机空缺也要如实建档 |
| 3 | 学习目标追问 | 阶段 1 | 🟡 | 至具体为止 | 不跳——决定教什么 |
| 4 | 计划呈现 | 阶段 2 | 🟡 非阻塞 | 1 次 | 展示即过，不等确认 |
| 5 | 考核页作答与提交 | 阶段 3 | 🔴 | 每小节 ≤4 题（question.html，浏览器作答提交自判分；报告贴回对话） | 未回报 → 悬空，下次补考 |
| 6 | 错题确认题 | 阶段 3（重教后） | 🔴 | 每条重教错题 1 题 | 答对才划销 |
| 7 | 使命修订确认 | 错题驱动/换目标 | 🟡 | 按需 | 修订使命前必须确认 |

**判分交互 = #5 + #6**，全部内聚在小节边界上——讲解正文零打断是流程的骨架性设计。

## 8. 跨会话循环（错题驱动）

```
会话 N 结束 ──→ 会话 N+1 开始
   │                 │
   │  lessons/ 课程 + answer.md 档案 ──→ 前沿定位（课程存在=已讲，档案有记录=已考）
   │  docs/answer.md ──────────→ 未清错题 → 教学顺序中优先重教 → 确认题 → 划销
   │  docs/resources.md ───────→ 情境知识支撑与社区偏好备注
   │                 ↓
   └─ 悬空小节 ──→ 并入会话 N+1 的考核节奏
   └─ 反复错题模式 ──→ 使命与方向优化的信号（修订前与学习者确认）
```

## 9. 可调参数表（优化入口）

| 参数 | 当前值 | SKILL.md 位置 | 调优权衡 |
|------|--------|---------------|----------|
| 教学起点 | 零基础默认，无测绘 | 阶段 1 | 若恢复测绘可精确定位，但打断感与开局成本回归 |
| 使命访谈轮数 | ≤2-3 | 会话开始 | 减 → 使命更模糊，教学锚更松 |
| 小节粒度 | 2-3 节点/小节 | 阶段 3 | 直接决定考核频次与课程产出粒度 |
| 小节考核题量 | ≤4 题（课程 HTML 题面 + 对话作答） | 阶段 3 / quiz 协议 | 改回 AskUserQuestion 弹窗 → 交互更快，但学习者失去"学完再答"的自定节奏 |
| 课程产出节奏 | 每小节必产出课程+考核页配对文件 | 阶段 3 | 若恢复按价值分流，考核需另找载体 |
| 答错处理 | 只记录不回头，下次重教 | 阶段 3 | 改当场补教 → 纠错更快，但节奏被打断 |
| 错题记录字段 | 题面\|错答\|正确答案\|小节\|日期 | 工作区清单 | 加字段（如误解类型）→ 分析更强，落盘更重 |
| 错题划销策略 | 重教 + 确认题答对划销，保留可见 | 阶段 3 | 改物理删除 → 文件干净，丢失错题史信号 |
| 教学形态 | 讲述式唯一（无 Socratic） | 原则 ii | 恢复切换 → 交互量剧增，与零打断承诺冲突 |
| 开场复习 | 无（错题融入教学流） | 会话开始 | 加开场复考 → 结构化更强，开场不再零交互 |
| 课程判定标准 | "有跨会话复习价值" | 阶段 3 去向判断 | 主观判断点，可收紧为客观条件 |
| 导航回填策略 | 快照不回填 | 课程（lessons） | 改回填 → 全局导航一致，维护成本线性涨 |
| maker 迭代预算 | ≤5 轮 | agents/diagram-maker.md | 子代理止损线 |
