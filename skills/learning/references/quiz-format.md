# quiz 协议——出题与判分

SKILL.md 教学流水线第 4 步（检索练习出题）执行本协议。判分题的可信度取决于干扰项是否像学习者真实的错误信念——选项构造程序是本协议的核心。

## 检索练习（默认）

- 产出阶段每节把 ≤4 道单选题追加进 lessons/0000-<主题名>检索练习.html——按节分组、"不知道"固定末项、答案内嵌 SECTIONS 数据（制作规范见 question-template.html 内注释）。
- 练习阶段学习者**凭记忆**逐节作答，全部答完**一次提交**全部判分——每题 ✓/✗ + 答案 + 简短解释，生成按节分块的作答报告（落档机制见工作区 answer.md 条目）。
- 答案内嵌页面脚本（源码可见）——自测场景可接受。

## 判分规则

- 选项恒为 4——1 正确 + 2 干扰 + 1 "不知道"（二选一辨析题允许 3 项）。"不知道"常驻不裁量——让"真不会"与"蒙错"可区分。
- 答案不进题面直读范围。
- 自然语言作答按核心断言判分：含实质错误即 ✗ 并指出错处，不为部分正确给 ✓；至多一轮澄清。
- 正确答案位置轮换——位置模式会泄露答案。

## 选项构造程序（所有判分题适用）

1. **每个选项都是裸断言**——理由一律放判分后的解释里；
2. 先写正确断言，再用**同骨架、同粒度、同语域**把它变异成每个干扰项——各选项是"不同信念下的同一断言"；
3. 干扰项必须是学习者**可能真犯的错**——诱人，不刁钻；
4. 加粗要么全无要么每项对应位置都有——只突出正确项会暴露答案。

写完冷读：不懂材料也能看出哪个对，就重新生成，不打补丁。
