# 配图（visualize）

一张图要配得上它的位置，前提是它表达了文字表达不了的东西——形状、结构、方向、关系、几何。本技能产出这样一张图，保证它**正确**（maker 分级验证后才返回），并把它以外链嵌进本节课程 HTML。

你是**创意总监**。你决定精确的创意，并把它蒸馏到最少的承载元素。**maker 子代理**负责创作与验证并保存，然后返回 SVG 文件名。你把该文件嵌进本节课程 HTML 正文对应的位置。

## 何时配图（何时不配）

本教学系统在学习者脑中构建**依赖图**——根部的无条件真理、挂在上面的推导事实。当图能让这个结构变得可见时，图才有力量。

散文或单个方程已经能承载时**不要**配图。一张只是复述旁边那句话的装饰性图，只添噪声、多一个出错机会。拿不准时，不配——缺一张图比错一张图便宜。

## 知识库图型选型表（六种，按教学场景选）

配图时按**教学内容**从下表选型——每种图绑定一个明确的教学场景，不在此表内的图型知识库不主动使用：

| # | 图型 | Mermaid 语法 | 教学场景（何时选它） |
|---|------|-------------|---------------------|
| 1 | **依赖图** | `graph TD` | 知识结构本身——无条件真理在根、推导挂在上面（核心教学法；课程的知识骨架） |
| 2 | **思维导图** | `mindmap` | 主题全景导览——课程开篇给学习者整体地图感 |
| 3 | **流程图** | `graph LR` | 技能操作步骤——"先做什么再做什么"的线性过程 |
| 4 | **时序图** | `sequenceDiagram` | 协议与交互——"谁在何时对谁说什么"（API 调用、握手、消息流） |
| 5 | **状态机** | `stateDiagram-v2` | 有状态的主题——状态迁移一目了然（HTTP 状态、进程生命周期） |
| 6 | **对比图** | `quadrantChart` 或双列 `graph` | 易混概念辨析——两个维度的分野，拆解学习者的误解 |

选型规则：先判断内容属于哪个场景，再取对应图型；一个场景一张图，不要同一节配两张同场景的图。手写 SVG（几何/函数图像）不在知识库选型表内——maker 保留该能力但不主动派发。

## 给 maker 的 brief 要好：一个想法，最少元素

最常见的失败是**塞爆**——每多一个标签，图就更难读，布局也更容易出错。brief 之前先剪到承载想法的最少元素，并对每个元素问："删掉它，想法还清楚吗？"清楚就删。

给 maker 创意*和*你想要的具体元素——不是模糊的话题，也不是长清单。

- 差："画一张 TCP 怎么工作的图"
- 好："graph TD：顶部一个节点'数据包'；两条箭头向下分别指向'排序'和'丢包重传'；两者再向下汇入'可靠字节流'。不要标题。要表达可靠性是从数据包*构建出来*的，不是与它并排的东西。"

保持想法完整，但相信 maker 的构图能力；如果你的 brief 列了超过约 5–7 个元素，先砍它。

## 调用

用 Agent 工具派发（`subagent_type="diagram-maker"`）。brief 必含三样：图型、极简具体的创意、**工作区 lessons/src/ 目录的绝对路径**——maker 的 cwd 未必是工作区，不给绝对路径它就会把图写错地方：

```
Agent(subagent_type="diagram-maker", description="课程配图",
      prompt="<图型>；<极简、具体的 brief>；工作区 lessons/src/ 目录：<绝对路径>")
```

maker 自己完成一切：创作、分级验证（mermaid 渲染临时 PNG 亲眼看 / SVG 源码审查）、迭代到正确干净，以唯一文件名把 **SVG 成品**存入指定 lessons/src/ 目录，然后返回：

```
RESULT:
filename: <slug>-<timestamp>.svg
path: <lessons/src/<slug>-<timestamp>.svg 的绝对路径>
```

**先验证 path 指向的文件真的存在，再嵌入**；块缺失或不可解析一律按 `NONE` 处理。

返回 `NONE` 时（仅 mermaid 类会因环境不可用走到这）：简化创意改派手写 SVG 一次，或判定这张图不值得——mermaid 源码在课程 HTML 中无法渲染。**绝不**自己动手画或伪造图；正确性依赖 maker 的分级验证。

maker 派发本身不可用时（环境不支持子代理、agent 未安装或派发失败），不要放弃配图：主线程亲自按 brief 手写 **SVG** 成品文件存入 lessons/src/（逐项源码审查几何与标签），并明确向学习者声明**"此图未经子代理验证"**。降级只减质量保证，不减配图。

## 嵌入课程

验证过文件真实存在后，把图嵌进**本节课程 HTML** 正文中讲解对应的位置。图存放在 `lessons/src/`，课程用 `src/` 前缀相对引用，按课程模板（template.html 的 `figure.fig`）给图一个干净的容器：

```html
<figure class="fig">
  <img src="src/<slug>-<timestamp>.svg" alt="一句话说明">
  <figcaption>一句话说明</figcaption>
</figure>
```

就这样。先用一句话引出这张图，然后让图自己承载想法——不要在散文里把每个元素复述一遍。需要控制宽度时给 `img` 加 `width="500"`。英文标签的配图（中文字体缺失的降级）要在教学回复里向学习者点明一句。

## 为什么这是可靠的

- mermaid 类 maker 返回前**一定看过**渲染像素，"渲染正常但说了假话"在学习者看到之前就被拦下；SVG 类经逐项源码审查（几何重算、方向对照）。
- SVG 是浏览器原生渲染的矢量——缩放不失真，maker 审查过的源码与学习者看到的渲染一一对应。
- 唯一文件名让嵌入解析无歧义。

> 依赖说明：**SVG 类零渲染依赖**——手写源码即成品，浏览器原生渲染，源码审查为验证基准（rsvg-convert/magick 可用时仅作可选预览增强）。**仅 mermaid 类**需要渲染链——`@mermaid-js/mermaid-cli`（Node 与 Chrome/Edge；找不到浏览器时 maker 会设 `PUPPETEER_EXECUTABLE_PATH` 补救一次），先出临时 PNG 亲眼验证、再出正式 SVG。你自己不渲染任何东西——只负责 brief 和嵌入返回的文件。
