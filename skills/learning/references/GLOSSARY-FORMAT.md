# glossary.md 格式

`glossary.md` 是本教学工作区的规范语言。所有讲解、练习和学习记录都应遵守它的术语。建立术语表本身就是学习的一部分：把一个概念压缩成一句紧凑的定义，就是学习者理解了它的证据。

## 结构

```md
# {主题} 术语表

{一两句话，描述本术语表覆盖的主题。}

## 术语

**肌肥大（Hypertrophy）**：
由机械张力和代谢压力在反复训练中驱动的肌肉生长。
_避免_：增重、练大块头

**渐进超负荷（Progressive overload）**：
通过负荷、容量或强度，随时间系统性提高对肌肉的需求。
_避免_：加大强度、升级

**RPE（自觉用力程度，Rate of Perceived Exertion）**：
对一组训练主观吃力程度的 1–10 自评：10 是力竭，8 表示还剩两次的余量。
_避免_：费力分、强度评分
```

## 规则

- **只在学习者理解了该术语时才收录。** 术语表是压缩知识的记录，不是学习者拿来学习的词典。如果学习者刚接触一个概念，等他们能正确使用它，再收进来。
- **要旗帜鲜明。** 同一概念有多个说法时，选出最好的一个，其余列为要避免的别名。语言就是这样压缩的。
- **定义要紧凑。** 一两句话。定义这个术语**是什么**，不是它做什么、怎么做。
- **定义内部使用术语表自己的术语。** 一个术语进了术语表，就处处用它，包括在其他定义里。这让复杂术语日后更容易被理解。
- **自然成簇时按子标题分组**（如 `## 解剖`、`## 编程`）。术语本来内聚时，平铺列表也可以。
- **明确标注歧义。** 如果一个术语在更大领域里用法不严格，写明本工作区的裁决："在本工作区，'组（set）'永远指正式组；热身组单独记录。"
- **理解加深时修订。** 学习者第一周写的定义，到第六周可能是错的。原地更新，不留过期条目。
