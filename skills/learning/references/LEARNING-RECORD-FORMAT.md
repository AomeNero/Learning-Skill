# 学习记录格式

学习记录存放在 `./learning-records/`，按顺序编号：`0001-slug.md`、`0002-slug.md` 等。目录惰性创建：写第一条记录时才建。

它们相当于教学版的 ADR（架构决策记录）：捕捉不显而易见的经验、关键洞见、以及会驱动后续会话的既有知识。用于计算最近发展区。

## 模板

```md
# {学到了什么或确立了什么的简短标题}

{1–3 句话：学到了什么（或确立了什么既有知识），以及为什么这对后续会话重要。}
```

这就是全部格式。一条学习记录可以只有一段。价值在于记录**现在已知道这件事**以及**为什么它改变接下来教什么**，而不在于填满各个小节。

## 可选小节

只在真正有价值时才加。大多数记录用不上。

- **Status** frontmatter（`active | superseded by LR-NNNN`）：当早先的理解被证明有误、被取代时有用。
- **Evidence**（证据）：学习者如何展示了该理解（答对一个问题、完成一个练习、引用既往经验）。当该论断可能被重新检验时有用。
- **Implications**（推论）：这为后续会话解锁了什么、排除了什么。不显而易见时值得记录。

## 编号

扫描 `./learning-records/` 中的最大编号，加一。

## 什么时候写学习记录

满足以下任一条就写：

1. **学习者展示了对某个不平凡之物的真正理解**：不只是接触过，而是有证据能正确使用该概念。这为接下来教什么设定了新的底线。
2. **学习者透露了既有知识**："我已经会 X。"记下来，后续会话就不会重教。同时记录所声称的**深度**。
3. **一个误解被纠正**：学习者此前相信错误的东西，现在明白了为什么错。这类记录价值很高：它们能预测相关主题未来的绊脚石。
4. **使命随学习发生了偏移**：学习者发现自己在意的和原以为的不同。交叉链接到 [[MISSION.md]] 并更新它。

### 不算数的

- 仅仅"讲过"的材料。讲过不等于学会。等证据。
- 已在 [[GLOSSARY.md]] 里作为术语定义简明记录过的东西。不要重复。
- 逐会话的活动日志。学习记录不是日记：是决策级的洞见。

## 取代

当后一条记录与前面的矛盾（学习者的理解加深或被纠正），把旧记录标记 `Status: superseded by LR-NNNN`，不要删除。理解如何演化的历史本身就是有用信号。
