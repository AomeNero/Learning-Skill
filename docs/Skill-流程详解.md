# Learning Skill 流程详解（维护者视图）

> 定位：**流程规格书**——供修改、优化 `SKILL.md` 时对照使用。按会话时间线组织：每个阶段给出步骤、交互属性、文件产物。所有可调数值（轮数、题数、粒度等）集中列在文末 [§9 可调参数表](#9-可调参数表优化入口)。
>
> 交互属性图例：🔴 **判分**（有对错，立即反馈）｜🟡 **对话**（不判分，收集偏好/信息）｜🟢 **无交互**（教师/子代理独立执行）｜📄 **产物**（文件落盘）

## 1. 会话开始（阶段 0）：工作区探测

| 属性 | 内容 |
|------|------|
| 触发 | 学习者明确表达学习意图（"教我 X"） |
| 交互 | 🟡 仅新工作区有使命访谈；续接**开场零提问** |
| 产物 | 📄 新工作区：`docs/MISSION.md` + `docs/RESOURCES.md` |

### 步骤

1. **选址**：当前目录是空目录或专用学习目录 → 就地作为工作区；非空一般目录（尤其代码仓库）→ 先确认目录（🟡 一次确认，默认建议独立目录）。
2. **探测**：`docs/MISSION.md` 不存在 → 新工作区；存在 → 续接。**兼容条款**：根目录 `MISSION.md` 属旧布局，原位沿用不迁移，读得到即视为已存在。
3. **新工作区分支**：使命访谈（🟡 不判分，≤2-3 轮；给不出动机就如实写"动机暂缺"——不许据此不建文件）→ 按格式初始化 `docs/MISSION.md` 与 `docs/RESOURCES.md`。
4. **续接分支**（🟢）：读 `docs/`（MISSION、全部 learning-records、NOTES）+ 工作区根 `GLOSSARY.md` + `log/` 本主题日志。**前沿 = 判分记录覆盖到的最后一个小节**；讲了但总判未覆盖的悬空小节并入下次总判，不当场补问。
5. **开场零提问**：不设开场复习——跨会话提取练习由会话末总判承担。

## 2. 阶段 1——探查（绝不跳过）

| 属性 | 内容 |
|------|------|
| 交互 | 🔴 1a 批量测绘（≤2轮×4题）+ 🟡 1b 目标追问 |
| 产物 | 无直接文件——测绘结果作为阶段 2 规划的输入（间接体现为日志里的依赖图起点） |

### 1a 批量测绘（🔴）

- **规模上限**：至多 2 轮 `AskUserQuestion`，每轮 ≤4 题，全程 ≤8 题。
- **排布**：第 1 轮 3-4 题沿课程依赖主线递阶（首题中等难度，逐题加码），一次测完主线。
- **核心原则——边界只有被夹住才算定位**：答对 = 地板（至少会这么多），答错/真不会 = 天花板（知识在此耗尽）。只有一边几乎说明不了什么。
- **第 2 轮触发条件**：全对 → 难度猛跳（不小步挪）；错答种类不明 → 围绕错误下钻（优先探明系统性误解的范围——误解要拆除，不是补充）。
- **以目标相关性为界**：只测教学要依靠的前置线。
- **出口**：空地板（整轮"不知道"且已到最基础概念）→ 从无条件真理起教，不出第 2 轮；拒绝降级（学习者明确拒绝）→ 说明目的、给一次选择，仍拒绝则按访谈信息设保守地板，总判兜底。
- **"不知道"选项**：常驻，不参与对错判分——让"真不会"与"蒙错"可区分。

### 1b 学习目标（🟡）

把愿景追问到具体为止（"我想理解 LLM"可以指十种东西）。无对错，只收集偏好。1b 之后若目标圈定的依赖线变化，下一轮（若有）补测新增线。

## 3. 阶段 2——规划（杠杆率最高的一步）

| 属性 | 内容 |
|------|------|
| 交互 | 🟢 摸底与设计；🟡 计划呈现（**非阻塞**） |
| 产物 | 📄 `log/<主题slug>.md` 创建；`docs/RESOURCES.md` 增量（摸底可信产出） |

### 步骤

1. **researcher 摸底**（🟢）：派 `researcher` 子代理测绘主题（核心概念、真正的第一性原理、标准讲法、常见坑）；不可用则自带搜索亲自摸底；两者都不可用则明示。**摸底不可省，只换执行者**。
2. **设计依赖图**（🟢）：确定无条件真理（有无原子单元形态）、学习者已持有的部分（1a 结果 + learning-records）、有动机的发现路径、知识/技能定性、反馈循环方案。
3. **压测根部**（🟢）：每个当作基础的节点问"对*这个学习者*它真是无条件真理，还是伪装的定理"——推得出来就压下去、把图延长。
4. **呈现计划**（🟡）：两部分——成段散文思路（覆盖什么、什么顺序、为什么，结合边界与目标与使命）+ 小型 mermaid 依赖图（根=无条件真理，汇点=目标）。**展示后不停留**：声明"有异议随时喊停"后直接进入阶段 3，无等待确认的阻塞点。
5. **落盘**（📄）：创建 `log/<主题slug>.md`，写入主题、使命摘录、学习目标、依赖图与教学顺序。slug 为 dash-case 英文意译，一经创建不再更改。

## 4. 阶段 3——教学（连续讲述，默认零交互）

| 属性 | 内容 |
|------|------|
| 交互 | 🟢 默认零提问；学习者**插问被动应答**；点名"让我自己推"才切 Socratic（其判分题仍判分） |
| 产物 | 📄 每小节：日志追加；小节去向分流：`lessons/`、`reference/`、`viz/` |

### 循环结构（以小节为单位）

```
对每个节点（无条件真理 + 非平凡推导步骤）：
  1. 给动机   —— 为什么现在需要它、解决什么问题
  2. 确立     —— 基础真理平直陈述 / 推导步骤走有动机的发现之路
  3. 连接     —— 依赖边显式化，新节点挂在哪些已就位节点上
每 2-3 个节点构成一个小节（日志镜像与总判的单位）
```

### 每教完一小节

- **日志追加**（📄）：讲解正文 + 进度标注（`> 进度：小节 3/5，总判未跑`）。
- **去向判断**（🟢）：有跨会话复习价值 → 整节成课 `lessons/NNNN-<slug>.html`（一文件一小节，TEMPLATE.html 三栏）+ `reference/` 压缩沉淀同步创建；仅过程记录 → 只留日志。
- **配图**（🟢，条件触发）：图确实比字更清楚时，`visualize` 技能派 `diagram-maker` 产出 PNG 到 `viz/`（源文件在 `viz/src/`），嵌入日志。

### 途中规则

- **准确性警报**：对任何事实有一丝不确定 → 停下核实（researcher / 自带搜索 / 明示未核实），准确性压过流畅。
- **信仰警报**：发现自己正断言一个学习者只能靠信仰接受的事实 → 停下：要么补动机，要么奠基到已确立的东西上。
- 小节全部讲完 → 进入阶段 4。

## 5. 阶段 4——总判（会话末，一次成批）

| 属性 | 内容 |
|------|------|
| 交互 | 🔴 全场唯一检验点：成批判分 + 当场补教 + 确认题 |
| 产物 | 📄 判分记录追加进日志 |

### 步骤

1. **成批出题**（🔴）：覆盖全部小节，每节 1-2 题，塞进尽量少的 `AskUserQuestion` 调用（每调用 ≤4 题，小节多就连发数次、中间不插讲解）；**混入**上次前沿的 1-2 道复习题 + 上次悬空小节的补判题（间隔复习与悬空验证免费发生）。
2. **题面先落盘**（📄）：总判题目写进日志，答案与解释等作答后再补——学习者在实时阅读日志，不提前泄底。
3. **当场判分**（🔴）：每题立即 ✓/✗ + 正确答案 + 简短解释。
4. **当场补教**（🔴）：答错的小节针对性重讲/换讲法，再出一道确认题钉住——不让会话在错误上结束。
5. **判分记录落盘**（📄）：每题一行——题面 | 学习者回答 | 判定 | 缺口说明。
6. **时间不够**：如实标注悬空小节并入下次总判，不让会话在未检验的小节上悄然结束。

## 9. 可调参数表（优化入口）

改流程时从这里入手——每行对应 `SKILL.md` 中的具体规则，调整前先想清楚它牵连什么：

| 参数 | 当前值 | SKILL.md 位置 | 调优权衡 |
|------|--------|---------------|----------|
| 测绘轮数 | ≤2 轮 | 阶段 1a | 减 → 更快开教但边界更粗；增 → 打断感上升 |
| 测绘每轮题数 | ≤4（工具硬上限） | 阶段 1a / quiz 协议 | AskUserQuestion 上限，不可超 |
| 测绘总题数 | ≤8 | 阶段 1a | 全程体验的"开局成本" |
| 使命访谈轮数 | ≤2-3 | 会话开始 | 减 → 使命更模糊，教学锚更松 |
| 小节粒度 | 2-3 节点/小节 | 阶段 3 | 直接决定总判题量与日志镜像粒度 |
| 总判题量 | 1-2 题/节 | 阶段 4 | 与小节数相乘 = 会话末交互总量 |
| 复习混入剂量 | 上次前沿 1-2 题 | 阶段 4 | 间隔复习的强度旋钮 |
| 课程判定标准 | "有跨会话复习价值" | 阶段 3 去向判断 | 目前是主观判断点，可收紧为客观条件 |
| 导航回填策略 | 快照不回填 | 课程（lessons） | 改回填 → 全局导航一致，维护成本线性涨 |
| Socratic 默认态 | 关（讲述式默认） | 原则 ii | 换默认 → 交互量剧增，与零打断承诺冲突 |
| 开场复习 | 无（零提问开场） | 会话开始 | 加开场复习 → 与"复习混入总判"重复 |
| maker 迭代预算 | ≤5 轮 | agents/diagram-maker.md | 子代理的止损线 |

## 10. 跨会话循环

```
会话 N 结束 ──→ 会话 N+1 开始
   │                │
   │  log/ 判分记录 + 进度标注 ──→ 前沿定位（判分覆盖到的最后小节）
   │  docs/learning-records ────→ 已确立地板 + 已知缺口
   │  docs/NOTES.md ────────────→ 教学姿态偏好
   │  GLOSSARY.md ──────────────→ 语言约束
   │                ↓
   └─ 悬空小节 ──→ 并入会话 N+1 的总判补判
   └─ 上次前沿 ──→ 复习题混入会话 N+1 的总判
```

下次会话从前沿继续而非重头再来；据此修补 lessons/reference 中被答错暴露的内容——教程跟着证据更新。
